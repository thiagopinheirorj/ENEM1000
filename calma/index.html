Enquanto espera

  1. Nomeie o que sente: "estou sentindo ansiedade / medo de abandono".
  2. Perceba onde está no corpo. Fique 90 segundos observando, sem obedecer.
  3. Pergunte: isso depende de mim? Se não, aceite. Se sim, qual é a menor ação útil?
  4. Faça algo com as mãos ou o corpo: caminhar, água fria, alongar.

Como usar

Manhã: preencha o que depende e o que não depende de você. Durante o dia: use o SOS e o registro de pensamento quando a ansiedade surgir. Noite: faça a revisão e conclua o dia.

Instalar no celular

Android (Chrome): menu ⋮ → "Instalar app". iPhone (Safari): Compartilhar → "Adicionar à Tela de Início". Depois funciona offline.

Seus dados

Tudo fica apenas neste aparelho (localStorage). Nada é enviado a servidores. Limpar os dados do navegador apaga tudo.

Aviso

Este app é uma ferramenta de autoajuda e não substitui acompanhamento psicológico. Se a ansiedade estiver intensa ou atrapalhando sua vida, procure um profissional. Em crise, ligue 188 (CVV, 24h, gratuito, no Brasil).
